Prism Browser Quality & Compatibility Checklist

Manual verification checklist for authentication, bot verification, fingerprinting, and popup handling.

Detecting...

1. Google & OAuth Authentication

Verify that Google does not show "This browser or app may not be secure". Ensure password, 2FA, and security prompts succeed.

Test on sites like StackOverflow or Feedly. The popup should appear, allow sign-in, and successfully communicate back via window.opener.postMessage and close.

Login with 2FA or passkeys. Ensure session survives restarts in persist:webcontent.

Verify Office/Outlook/Live login flows without hanging on redirect query parameters.

2. Bot Detection & Cloudflare Challenges

Verify that Turnstile checkboxes resolve and do not loop endlessly on "Checking your browser...".

Confirm that verification scripts load without being blocked by EasyList or content filters.

Ensure challenge APIs are completely allowlisted and interact smoothly.

3. Fingerprint & API Sanity Checkers

Check that navigator.webdriver is false/missing, window.chrome exists, plugins/languages are valid, and User Agent matches Client Hints.

Inspect Client Hints (sec-ch-ua, sec-ch-ua-platform) and ensure consistency with the Chrome User-Agent.

4. Privacy & Shields UI

Open tab editor on any site, click shield icon. Verify blocked item count is displayed and the toggle disables filtering for the current site when needed.

Navigate to an invalid SSL test site (e.g. https://self-signed.badssl.com/). Confirm user is warned and given an explicit choice to proceed or return.
